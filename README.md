# DAA-PRACTICAL-7
Summary

The Making Change Problem finds the minimum number of coins needed to make a given amount. Dynamic Programming stores solutions to smaller subproblems to avoid repeated calculations. This improves efficiency compared to recursive approaches.

Conclusion

Dynamic Programming provides an optimal solution for the coin change problem. It reduces computation time by reusing previously computed results. The algorithm has a time complexity of O(n × amount) and a space complexity of O(amount).
